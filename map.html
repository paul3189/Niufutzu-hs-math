🧭拆解問題的四個提問

① 這題「問什麼」？

  • 求一個值 → 解方程式／代公式
  • 求範圍 → 不等式、判別式、值域
  • 求個數 → 計數、判別式、圖形交點
  • 求最大最小 → 最值策略表（7 條路）
  • 求位置關係 → 距離 vs 半徑、向量、行列式
  • 要證明 → 從定義出發、歸納法、反證

② 題目「給了什麼」？

  • 給幾個點的坐標 → 坐標幾何／向量
  • 給邊與角 → 正弦、餘弦定理
  • 給前後項關係 → 數列與遞迴
  • 給條件機率式的敘述 → 樹狀圖、貝氏
  • 給對所有 x 成立 → 恆成立轉最值
  • 給一堆數據 → 平均與標準差、相關係數

③ 我有「哪些工具」？

  • 同一件事常有 代數解 與 幾何解 兩條路
  • 算不出來時，換一個表示法：
    坐標 ↔ 向量 ↔ 三角 ↔ 複數
  • 式子太複雜 → 換元（記得換範圍）
  • 正面難算 → 補集、反證
  • 看不出結構 → 先畫圖、先試小的 n

④ 這個工具的「限制」是什麼？

  • 分母 ≠ 0、根號內 ≥ 0、真數 > 0
  • 平方 / 去絕對值 → 一定要驗根
  • 公比 r ≠ 1、底數 a > 0 且 a ≠ 1
  • 不等式乘負數 → 變號
  • 算幾／柯西 → 等號能不能成立
  • 換元後 → 新變數的範圍

💡怎麼用這張圖

平常讀書時：每讀完一章，回到這張圖找到它的位置，問自己「它跟旁邊的主題有什麼關係？」—— 孤立記住的公式最容易忘，長在樹上的公式才叫理解。

寫題目卡住時：不要馬上翻解答。先問「這題屬於哪個領域？」→ 進入該分支圖 → 掃過那個主題的所有工具 → 逐一問「這個工具的觸發條件，題目有沒有給？」

訂正錯題時：錯的往往不是計算，而是「限制沒檢查」。到工具的限制／前提欄 找到你踩的那個坑，把它抄進錯題本。

考前複習時：把每個領域的分支圖印出來，遮住「工具」欄，只看「什麼時候用」，測試自己能不能反射性地說出工具名稱。
